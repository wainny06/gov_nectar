# 넥타 지원사업 데스크

K-뷰티·중소기업·여성기업 지원사업을 관리하는 대시보드 시험판입니다.

## Vercel 배포

이 저장소를 Vercel의 Add New → Project에서 Import하세요.

- Framework Preset: **Other**
- Root Directory: **./**
- Build Command: **npm run build**
- Output Directory: **dist**
- Node.js: **22.x**
- 환경변수: 필요 없음

배포 설정은 `vercel.json`에 포함되어 있습니다. 화면은 정적 파일로, 공고 수집은 `/api/refresh` 서버 함수로 분리했습니다. 자세한 설명은 [DEPLOY.md](DEPLOY.md)를 참고하세요.

## 로컬 실행과 검증

```sh
npm run dev
npm run build
npm test
```

개발 주소: http://localhost:3000

## 기능

사업명·지원내용·조건·마감일·신청 상태·담당자·메모·원문 관리, 기관/분야/키워드 검색, 마감일 정렬, JSON 백업 및 복원, 기관별 수동 새로고침.

## 현재 범위

- 데이터는 현재 브라우저에 저장됩니다. 여러 기기의 공동 저장은 아직 연결하지 않았습니다.
- 기관별 수집은 공개 HTML에서 제목과 링크를 추출하는 초안입니다. 모든 기관의 연동 성공, 페이지네이션, 첨부파일 분석, 상세조건·마감일 자동 추출, 기관 간 동일사업 통합은 아직 완료되지 않았습니다.
- 불명확한 정보는 원문 확인 필요로 표시합니다. 초기 공고 1건은 2026-09-14 고비즈코리아 공식 원문을 확인해 등록했습니다.
- 1.0.1: 정적 빌드와 API 분리, 배포 프레임워크 명시, 잘못된 JSON 처리 보완. 빌드 및 회귀 검사 6개 통과. 실제 배포 후 화면과 기관별 수집은 별도 확인이 필요합니다.

## 2027 준비 워크스페이스

`/planning.html`에 2025년 공고 근거 14개 준비카드와 72개 권장 작업을 제공합니다. 2027 공고·일정은 미확정이며 반복 확인 여부와 과거 접수기간을 구분합니다. 내부 목표일·담당자·체크·메모는 별도 localStorage 키에 저장합니다. 이 화면의 백업은 기존 대시보드 백업과 별개입니다. 모든 지원사업의 전수조사 또는 신청자격 판정은 아닙니다.

## 화장품 인증·공모

`/beauty.html`에는 2025년 공고에 근거한 인증·등록비, 시험·안전성, 공모·우수제품 선정 9개 카드와 44개 준비 작업이 있습니다. 지역 조건과 미확인 항목을 구분하며 2027년 재개는 확정하지 않습니다. 기존 준비 화면과 저장·백업은 분리됩니다. 일반·패스트트랙은 같은 사업이므로 한도 합산에 주의합니다.

## 2026 현재 공고 및 자금지원 보완

2026-09-14 확인 공고 6건(화성 마케팅 1, 자금 관련 5)을 기존 브라우저 데이터에 병합합니다. 직접 편집·삭제·상태·메모는 유지하며 기업마당 URL 변형은 중복 방지합니다. 화성 새로고침은 포털과 기업마당 화성 검색 3페이지를 함께 조회합니다. 실시간 추출 실패 시 snapshot 상태로 과거 확인자료만 반환하며 최신 접수상태를 확인했다고 표시하지 않습니다. 지역 포털 인증서/접속 오류로 실제 외부 수집의 전 과정 검증에는 제한이 있습니다.
